# Design lock

Reject the dispatch until every item has a concrete answer:

1. Layout — regions, hierarchy, what is primary.
2. Type — family, sizes, what is scan vs hit.
3. Color — background, text, state (not mood).
4. Density — compact working tool vs airy marketing.
5. States — default, loading, selected, disabled, live.
6. Empty and error — what the screen shows when there is nothing, and when it fails.
7. Keyboard — focus order, submit, shortcuts if any.

Post the lock in the shipping room. Then Planner. No Executor on a partial lock.
