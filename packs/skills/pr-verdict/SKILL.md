# PR verdict

1. Diff vs the locked plan, not vs taste.
2. Approve only if the PR implements the plan and nothing material extra.
3. Request changes if it drifts, skips a done-when, or touches out-of-scope paths (hub UI, `eve/`, ledger rebuild).
4. Comment if you need a question answered before a verdict.
5. Never merge from this skill. `log_entry` the verdict.
