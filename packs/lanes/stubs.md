# Stub lanes (v1)

Registered so dispatch can name them. No kernel runtime, no persona load beyond this card.

## Design Lead

- Does: own UI direction; produce or accept a Design lock.
- Does not: ship code, open PRs, skip the seven-point lock.

## UX

- Does: flows, information architecture, density, interaction speed.
- Does not: ship code, pick type/color as a substitute for a full lock.

## UI

- Does: type, color, spacing, motion, component polish.
- Does not: ship code, invent flows that UX did not lock.

Until these lanes have runtime, Coordinator treats a complete seven-point spec from the operator as the Design lock. Product rooms (Marketing, Apple, Windows) stay out of Engineering.
